# TaxPro2Profit Return Assistant

Private, source-governed training and decision-support software for new and entry-level professional tax preparers.

## Phase 2 included
- Next.js / TypeScript / Tailwind application shell
- Responsive TaxPro2Profit visual foundation
- Dashboard and navigation to all MVP work areas
- Onboarding, safety, privacy, and source-grounding UI states
- Coach Cocoa Tip presentation component
- Explicit no-answer placeholders until source ingestion and retrieval are implemented

## Run locally
1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Phase 2 test checklist
- Verify the dashboard renders on mobile and desktop.
- Verify each workspace card navigates to a functional route.
- Verify all workspace routes display a no-tax-answer safety state.
- Verify keyboard focus is visible.
- Verify privacy and decision-support notices are visible.

## Not included yet
Authentication, roles, database access, source upload, document extraction, vector retrieval, AI calls, actual tax decision workflows, or tax answers.
